## 契约变化

| 范围 | 接口与验证重点 |
| --- | --- |
| 执行报告 | `GET /reports/executions` 分类、分页、状态及日期校验；`GET /reports/executions/{id}` 项目隔离与父子报告。场景步骤保存在 `detail.steps`，套件/回归执行使用 `children` |
| 显式回归 | `GET /regression/options`；`POST /regression/preview` 只读预览和去重；`POST /regression/run` 校验 `preview_key`，配置变更后 409，不产生报告；成功执行形成可追溯报告树 |
| 项目通知 | `GET/PUT /projects/{id}/notifications` 权限、配置状态、凭证不回显及显式清除；未配置时 `POST .../test` 返回 400；无效目标 422。回归通知未配置时保留执行成功和报告，返回警告 |
| 调试录制 | `GET /traffic/capture`、`POST .../start`、`POST .../stop` 用户隔离、重复开始、停止与重新开始；`GET /traffic/records` 按录制批次分页；跨项目明细 404 |
| 流量回放 | `POST /traffic/replay/{id}` 调试记录必须选择环境；脱敏认证字段必须补充；显式空 Query 和 null Body；回放响应比较和凭证脱敏；跨项目 404 |
| 压测编辑/复用 | `PUT /perf/tasks/{id}` 更新配置；重复 `POST .../run` 生成独立执行 ID，清空上次实时指标；运行中的重复启动和编辑 409 |
| 压测历史 | `GET /perf/tasks/{id}/runs` 分页边界、倒序、历史配置快照；`GET .../runs/{run_id}` 明细与隔离；`POST .../runs/clear` 清除选中/全部完成记录，拒绝无效和运行中记录，缺失 ID 不部分删除，保留任务配置并恢复最近剩余结果 |
| 实时事务指标 | 运行期间读取任务及执行明细，结束后验证 `iteration_stats` 与 TPS 采样：累计数量/实际耗时、成功 TPS、相邻样本的区间 TPS。单接口一轮及多步骤完整链路各作为一个事务 |

前端布局、按钮文案、套件选择器、报告标签和 Cron 展示没有单独扩展接口回归。旧接口与原有测试继续保留；接口/用例 PUT 仍使用完整请求模型，脚本不会把它当成局部 PATCH。

## 执行方式

离线运行需安装两仓依赖，后端位于相邻 `WhaleTestPro`，或设置 `WHALE_BACKEND_PATH`。缺少后端或接口不会静默跳过。

```powershell
$env:LOCUST_SKIP_MONKEY_PATCH='1'
python -m pytest tests --reruns 0
```

HTTP 运行使用可重置的独立服务。`WHALE_BASE_URL` 是测试进程访问后端的地址，`WHALE_RUNNER_BASE_URL` 是后端访问自身健康检查的地址。回放/压测模拟地址必须从后端、Locust 容器可达；模拟服务使用 `scripts/perf_fixture_server.py --host 0.0.0.0 --port 8090` 启动。

```powershell
# 先设置 WHALE_BASE_URL、WHALE_RUNNER_BASE_URL 指向独立环境。
$env:WHALE_CORE_ALLOW_WRITES='1'
$env:WHALE_REPLAY_FIXTURE_BASE_URL='http://fixture:8090'
python -m pytest testcases/test_core/test_platform_delta.py --reruns 0

$env:WHALE_PERF_CORE_ALLOW_WRITES='1'
$env:WHALE_PERF_ALLOW_LOAD='1'
$env:WHALE_PERF_FIXTURE_BASE_URL='http://fixture:8090'
python -m pytest testcases/test_perf_core/test_perf_history.py --reruns 0

Remove-Item Env:\WHALE_CORE_ALLOW_WRITES, Env:\WHALE_REPLAY_FIXTURE_BASE_URL
Remove-Item Env:\WHALE_PERF_CORE_ALLOW_WRITES, Env:\WHALE_PERF_ALLOW_LOAD, Env:\WHALE_PERF_FIXTURE_BASE_URL
```

未开启写入时核心/压测测试跳过；未开启流量开关或未提供专用目标时异步压测跳过。开启核心写入后，回放用例要求配置专用目标。CI 已提前启动现有模拟服务并设置回放目标，两个核心目录的门禁会自动收集新增脚本。

只删除本轮登记的任务、项目和团队；压测停止/清理未确认成功时保留项目并报错。无账号删除接口，新建测试账号由独立测试数据库的销毁清理。通知用例只调用未配置的测试接口，或保存禁用的合成配置，从不向已配置 Webhook 发消息。
