## 运行与隔离

1. 安装测试仓库依赖。离线门禁另需后端源码和后端依赖，可设置 `WHALE_BACKEND_PATH`。
2. HTTP 回归只使用可重置的隔离环境，设置 `WHALE_CORE_ALLOW_WRITES=1` 才执行；未设置时 29 个场景明确跳过。
3. `WHALE_BASE_URL` 是测试进程访问后端的地址；`WHALE_RUNNER_BASE_URL` 是后端执行引擎访问 `/health/live` 的地址。Docker Compose 默认分别为 `http://localhost:8001` 和容器内 `http://localhost:8000`；其他部署须重新配置。
4. 新核心子目录覆盖旧的账号前置，不清理共享 Redis 登录限流，不使用配置中的既有测试账号。每会话注册 3 个新账号，仅 owner/member 加入本轮团队；outsider 不加入。
5. 每个场景创建独立团队/项目，结束时只删除本轮登记的项目和团队，项目级联清理其资产与报告。没有账号删除接口，注册用户会留在测试库，运行后由隔离环境的重置流程处理。遇到清理失败直接报错，不静默忽略。
6. 不执行压测、定时调度、SQL 故障注入或通知。默认登录限流为 5 次/60 秒，同 IP 短时间连续重跑可能返回 429；等待窗口到期，不清空共享限流键。首次执行使用 `--reruns 0`，避免重跑混淆结果。
7. 仓库 `config.py` 使用进程环境变量优先、`.env` 仅补未设置默认值的规则。运行前检查进程中的 `WHALE_BASE_URL`、`WHALE_RUNNER_BASE_URL`、`WHALE_PERF_BASE_URL` 和 `WHALE_PERF_FIXTURE_BASE_URL`；若改用 `.env` 默认值，先用 `Remove-Item Env:\WHALE_BASE_URL -ErrorAction SilentlyContinue` 移除对应遗留进程变量（其余目标变量同理），再启动测试进程，避免误指向已有/生产环境。

```powershell
# 在 WhaleTestPro-APITest 目录执行；地址只适用于隔离的默认 Compose 部署。
$env:LOCUST_SKIP_MONKEY_PATCH='1'
$env:WHALE_BASE_URL='http://localhost:8001'
$env:WHALE_RUNNER_BASE_URL='http://localhost:8000'
$env:WHALE_CORE_ALLOW_WRITES='1'
python -m pytest testcases/test_core --reruns 0 --alluredir=allure-results
# 只跑本次 5 条冒烟：追加 -m smoke。
Remove-Item Env:\WHALE_CORE_ALLOW_WRITES
```

离线验证（不访问部署环境，也不需要写入开关）：

```powershell
$env:LOCUST_SKIP_MONKEY_PATCH='1'
python -m pytest tests --reruns 0
```
